# 🏛️ [정부지원사업 표준 사업계획서 (PSST 양식)]
## 예비·초기창업패키지 / TIPS / 디딤돌 R&D 지원용

```
[과제명]
온디바이스(On-Device) WebGPU AI 및 클라이언트 사이드 미디어 스튜디오가 통합된 
기업 기밀 유출 0% 엔터프라이즈 마크다운 워크스테이션(AMEVA) 개발
```

## 1. Problem (문제 인식)

### 1-1. 창업 아이템의 개발 동기 및 필요성
1. **생성형 AI 도입에 따른 기업 대외비 및 지식재산권(IP) 유출 위기 심화**:
   * 대다수 기업이 생산성 혁신을 위해 생성형 AI(OpenAI, Claude 등) 도입을 희망하고 있으나, 데이터가 외부 클라우드 서버로 전송되어 학습에 재사용되거나 해킹당할 위험으로 인해 **금융사, 방위산업체, 의료기관, 대기업의 74% 이상이 사내 AI 사용을 금지하거나 제한**하고 있음.
   * 기존 온프레미스 AI 구축은 수억~수십억 원에 달하는 고가의 전용 GPU 서버(NVIDIA H100/A100) 구축 비용이 발생하여 중소기업 및 스타트업은 접근이 불가능함.
2. **소프트웨어 툴 파편화(Tool Fragmentation)로 인한 지식 근로자 생산성 저하**:
   * 문서 작성 중 비디오 자르기(Premiere), 이미지 누끼따기(Photoshop), 오디오 무음 제거(Audacity), 지도 검색(Google Maps), 코드 실행(Jupyter) 등 **평균 8개 이상의 별도 프로그램을 오가며 작업**하고 있어, 과도한 컨텍스트 스위칭 비용과 연간 수백만 원의 소프트웨어 구독료가 낭비됨.

### 1-2. 대상 시장의 규모 및 성장 잠재력
* **글로벌 온디바이스 AI 시장**: 2024년 185억 달러에서 2030년 **1,200억 달러(연평균 성장률 37.8%)** 규모로 폭발적 성장 전망.
* **글로벌 협업 및 생산성 소프트웨어 시장**: 2026년 기준 약 **785억 달러(약 105조 원)** 규모로, 보안 특화 올인원 워크스페이스에 대한 수요가 급증하고 있음.

## 2. Solution (실현 가능성 및 개발 방안)

### 2-1. 창업 아이템의 핵심 기능 및 차별성

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           AMEVA 핵심 기술 파이프라인                             │
├──────────────────────────┬──────────────────────────┬───────────────────────────┤
│ 1. On-Device WebGPU AI   │ 2. In-App Media Studio   │ 3. Zero-Server VFS & CRDT │
│ • Qwen2.5 0.5B/1.5B/7B   │ • 비디오 8방향 컷편집     │ • 로컬 IndexedDB 암호화   │
│ • Whisper 음성 인식      │ • Fabric.js 캔버스/누끼  │ • P2P / 릴레이 실시간 협업│
│ • 3단계 문서 맵리듀스    │ • 오디오 무음 자동 삭제  │ • `.adc` 단일 아카이브    │
└──────────────────────────┴──────────────────────────┴───────────────────────────┘
```

1. **클라우드 서버비 $0 & 100% 프라이버시 WebGPU 가속 엔진**:
   * 사용자의 로컬 PC 브라우저 내부 WebGPU 텐서 가속기를 통해 Qwen2.5 LLM 및 경량 비전/오디오 모델을 로컬에서 실시간 구동(초당 35+ 토큰 속도).
   * **외부 서버 데이터 송수신 0byte로 기업 기밀 유출 위험 원천 차단**.
2. **올인원 멀티미디어 저작 스튜디오 (Video·Image·Audio)**:
   * **비디오**: 타임라인 기반 초 단위 컷편집 및 8방향 비례 리사이징.
   * **이미지**: Fabric.js 캔버스 드로잉, AI 1초 배경 제거(Remove BG), 사진별 개별 리사이즈.
   * **오디오**: 파형(Waveform) 시각화 및 **⚡ 무음 구간 자동 감지 후 1-클릭 일괄 삭제**.
3. **대용량 다중 문서 인텔리전스 (Doc Intelligence)**:
   * PDF, Word(`.docx`), PPTX, 한글(`.hwpx`)을 브라우저에서 즉시 파싱.
   * 소형 문서는 **3초 고속 패스(Fast-Pass)** 요약, 대형 문서는 **3단계 맵리듀스(Map-Reduce)**를 통해 챕터별 카드 요약 덱(Deck) 자동 생성.
4. **인터랙티브 지오매핑 (Geo-Mapping)**:
   * Leaflet & OpenStreetMap 기반 장소 검색, 다중 핀(Multi-Pin) 꽂기, 출발-도착 최적 경로 탐색 및 마크다운 영구 연동.

### 2-2. 기술 개발 추진 현황 및 실현 가능성 검증
* **TRL (기술성숙도) 7단계 달성**: 실제 운영 가능한 웹 애플리케이션 및 PWA 클라이언트 구현 완료.
* **라이브 데모 가동 중**: [https://ameva-workstation-web-core.vercel.app/](https://ameva-workstation-web-core.vercel.app/)
* **오픈소스 저장소 공개 및 검증**: GitHub 저장소를 통한 글로벌 개발자 커뮤니티 코드 검증 완료.

## 3. Scale-up (성장 전략 및 비즈니스 모델)

### 3-1. 비즈니스 모델 및 수익화 방안

```
1. B2C Freemium (무료 유저 풀 확보)
   - 온디바이스 AI, 미디어 스튜디오, 로컬 VFS 전면 무료 제공 ➔ 바이럴 및 글로벌 표준화

2. B2B Pro / Team (SaaS 구독: 월 15,000원 / user)
   - 팀 단위 Y.js 실시간 P2P/릴레이 협업, 지식 베이스 동기화, 클라우드 백업

3. Enterprise On-Premise (설치형 라이선스: 기업당 연 5,000만 원 ~ 2억 원+)
   - 망분리 대기업, 금융사, 방산, 의료기관 전용 오프라인 라이선스 DRM
   - 사내 전용 도메인 파인튜닝 모델 패키징 및 보안 감사 로그 시스템 제공
```

### 3-2. 원가 경쟁력 및 수익성 (Unit Economics)
* **초고마진 구조 (Gross Margin 92% 이상)**:
  * 경쟁 서비스는 유저가 AI를 쓸 때마다 OpenAI 등에 막대한 API 비용을 지불해야 하나, AMEVA는 **연산 비용을 유저의 하드웨어(PC/노트북)가 전담**하므로 고객사 수백만 명이 증가해도 서버 비용이 거의 증가하지 않는 한계비용 제로($0) 비즈니스 모델 구축.

### 3-3. 시장 진입 및 마케팅 전략
1. **1단계: 개발자 및 테크 얼리어답터 확보 (1~6개월)**:
   * GitHub 오픈소스 커뮤니티, Hacker News, GeekNews, Reddit을 통한 글로벌 바이럴.
   * WebGPU 기반 신기술 쇼케이스로 글로벌 5,000+ GitHub Star 유치.
2. **2단계: 제품 주도 성장 (PLG, 6~18개월)**:
   * 개인 사용자가 사내 업무에 도입한 후 팀 단위 Pro 요금제로 유료 결제 전환 유도.
3. **3단계: B2B 엔터프라이즈 공공/금융 공략 (18~36개월)**:
   * CSAP(클라우드 보안인증), ISMS-P 인증 취득 및 조달청 혁신제품 등록을 통한 공공/국방 시장 독점 진입.
